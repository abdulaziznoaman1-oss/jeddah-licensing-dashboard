# نشر داشبورد منصة التراخيص - نسخة آمنة للنشر

هذه الحزمة لا تحتوي على سجلات التراخيص. يبدأ الخادم بقاعدة بيانات فارغة عند أول تشغيل.

## تشغيل الموقع على Render

1. أنشئ مستودع GitHub خاصا وارفع إليه محتويات هذه الحزمة.
2. اربط حساب Render، ثم اختر New > Blueprint، واختر المستودع.
3. يعتمد النشر على render.yaml، ويتطلب قرصا دائما (قد يكون مدفوعا).
4. أدخل كلمات مرور قوية ومختلفة لـ VIEW_PASSWORD و ADMIN_PASSWORD في إعدادات الاستضافة.
5. بعد النشر، افتح رابط HTTPS الذي يصدره Render وسجل الدخول بكلمة مرور المسؤول.
6. ارفع ملف Excel داخل المنصة من خيار رفع البيانات، ثم شارك رابط الموقع وكلمة مرور المشاهد مع الأشخاص المصرح لهم فقط.

## تنبيهات

- لا تنشر ملف بيانات Excel أو HTML السابق الذي يتضمن السجلات في مستودع عام.
- استخدم استضافة معتمدة من تقنية المعلومات، وراجع متطلبات الخصوصية والسياسات الداخلية قبل النشر.
- هذه نسخة تجريبية بحماية كلمة مرور. للاستخدام المؤسسي يفضل تفعيل الدخول المؤسسي SSO، النسخ الاحتياطية، والتدقيق والصلاحيات التفصيلية.
- لا يوجد رابط منشور حتى يتم ربط حساب الاستضافة وتفعيل النشر.
